# 单词砍砍乐（Word Memory App）

一个可安装到手机、iPhone、iPad、Android 平板和电脑的 PWA 英语单词记忆工具。支持只导入英文后自动生成完整词条、自定义复习计划、英中双向遮挡记忆、薄弱方向优先训练、“熟练后砍掉”和离线复习。

## 主要功能

- **批量导入只需要英文**：每行一个英文单词/短语，也支持 TXT / CSV。
- **自动生成完整词条**：音标、词性、常用中文释义、英文例句、例句中文翻译。
- **三种背诵模式**：
  - 双向智能：英→中、中文→英文自动平衡，优先训练较弱方向。
  - 隐藏中文：看英文回忆词性和中文释义。
  - 隐藏英文：看中文释义输入英文单词。
- **双向深度记忆**：可设置“同一阶段两个方向都通过才进阶”。在双向智能模式下，一个方向答对后，本轮会再考另一个方向。
- **完全自定义复习计划**：每个复习阶段都可以自己设置分钟 / 小时 / 天，并可随时增加或删除阶段。
- 内置三套计划：经典艾宾浩斯、强化记忆、轻量长期。
- 可设置**每日学习总上限**和**每日新词上限**，避免一次导入大量单词后任务过重。
- 四档反馈：没记住 / 有点模糊 / 记住了 / 很熟练·砍掉。
- 支持英文发音、学习统计、词库搜索、JSON 完整备份/恢复、CSV 导出。
- 学习记录默认保存在设备本地 `localStorage`。
- **PWA 可安装**：安装后从桌面图标直接打开，以独立 App 窗口运行，不显示浏览器地址栏。
- **离线复习**：已经生成的词条和学习记录可离线使用；自动生成词条时需要联网。

## 自动词条生成

程序会组合使用公开在线服务获取/生成词性、音标、中文释义和例句。因此自动生成新词条需要联网。生成完成后，日常背诵、复习、砍词和学习进度记录可以离线完成。

> 公共 API 的可用性、限流和返回质量可能变化，因此保留手动录入、失败重试和旧词补全功能。

## 自定义复习计划

进入 **复习计划** 可以自行设置，例如：

`10分钟 → 1天 → 2天 → 4天 → 7天 → 15天 → 30天 → 完全掌握`

也可以改成你自己的节奏，例如：

`5分钟 → 30分钟 → 6小时 → 1天 → 3天 → 7天 → 14天 → 30天`

保存时可以选择：

- **保存计划**：之后的新复习按新计划执行。
- **保存并按新计划重排未掌握单词**：现有学习中的单词也立即重新计算下次复习时间。

## PWA 安装

### iPhone / iPad

1. 用 Safari 打开 GitHub Pages 地址。
2. 点击“分享”。
3. 选择“添加到主屏幕”。
4. 以后直接点击桌面的“单词砍砍乐”图标进入。

### Android 手机 / 平板

1. 用支持 PWA 的浏览器打开 GitHub Pages 地址。
2. 选择“安装应用”或“添加到主屏幕”。
3. 安装后以后直接从桌面图标启动。

## GitHub Pages

仓库文件放在 `main` 分支根目录后：

1. 打开仓库 **Settings → Pages**。
2. Source 选择 **Deploy from a branch**。
3. Branch 选择 `main`，目录选择 `/ (root)`。
4. 保存，等待 GitHub 生成 HTTPS 地址。

PWA 安装需要 HTTPS；GitHub Pages 正好满足这个要求。
